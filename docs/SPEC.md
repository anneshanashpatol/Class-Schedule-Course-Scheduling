# 青禾排课第一版规格

本系统服务小型培训机构的管理员、教师和学生。管理员维护用户与全部排课；教师维护自己的课程；学生查看与导出自己的课程。姓名是唯一登录账号，用户删除为停用，历史排课关系永久保留。

## 关键规则

- 固定 60 分钟为 1 课时，课时和余额以百分之一课时整数存储。
- 新课程默认未完课；完课扣减学生余额，取消完课返还；重复请求必须幂等。
- 已完课课程锁定学生、日期和时间；删除课程永不联动余额。
- 教师、学生和非空教室在同日不能出现时间重叠；首尾相接允许。
- 教师科目和排课科目都是自由文本，互不绑定。
- 教师只能单条删除自己的课程；批量删除仅管理员可用。

## 边界

- 必须由后端执行权限、停用、锁定和冲突校验；前端限制仅用于改善体验。
- 密码、会话令牌和部署授权不得进入仓库。
- 第一版不实现通知、财务、班级、多校区、审批、回收站和审计后台。

## 验收

以用户提供的《排课系统第一版实施计划》第 5 节为准。类型检查、单元与集成测试、构建以及三角色浏览器核心路径均需通过。
